## Overview

This repository contains solutions for the Python Programming Assessment provided by Embed Square Solutions.

The assessment focuses on fundamental Python programming concepts related to string manipulation and data processing.

The implemented solutions cover:

1. Reverse a String
2. Count Vowels in a String

Each problem is implemented in two ways:

- User Input Version
- Hardcoded Input Version

The solutions are written using clean, readable, and beginner-friendly Python code.

---

## Approach

### Question 1 – Reverse a String

- Traverse the string character by character.
- Construct a new string in reverse order.
- Return the reversed string.

### Question 2 – Count Vowels

- Traverse each character in the string.
- Convert characters to lowercase for case-insensitive comparison.
- Check whether the character is a vowel (`a, e, i, o, u`).
- Count and return the total number of vowels.

The code also handles empty strings and works correctly for both uppercase and lowercase characters.

## How to Run the Programs

Run the Reverse String program:

```bash

```

Run the Count Vowels program:


### Method 2 – Using Visual Studio Code

1. Open Visual Studio Code.
2. Open the project folder.
3. Select the Python interpreter (Python 3.10 or above).
4. Open any Python file.
5. Click **Run Python File** or press:

```

```

Open the integrated terminal and execute:
